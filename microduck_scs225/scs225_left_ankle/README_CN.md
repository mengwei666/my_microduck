# 左踝 SCS225 完整适配：05 小腿切端 + 抱箍外壳 + C 形连杆

## 0. 方案（按你选的）

- **05 小腿**：切掉原来的踝端 U 形夹（05 坐标 `x < -4 mm`），保留后面的平板，
  在板上加两个 M3 夹紧孔。
- **05/06 抱箍外壳**：一块 `52 × 32 × 10 mm` 的转接块，背面夹住 05 小腿的平板，
  正面装 SCS225 背面；背面同时用 3× M2.5 固定到 06 `ankle_left`。
- **C 形外置连杆**：从 SCS225 舵盘（4×M2.5，R7）出发，绕到机体 `+Y` 侧，
  再从脚踝拨片上方下 M3 销，驱动脚。

> 这一版是 **尺寸/装配验证件**，不是最终外观件。05 切腿不可逆，建议先打印
> 测试腿和外壳试装。

## 2. 关键尺寸

### 05 小腿切端

- 切割位置：05 坐标 **x = -4 mm**，保留 `x ≥ -4` 的平板
- 切后平板大约：`z = 18.5~21.5`（厚约 3 mm），`y = -10~5`
- 夹紧孔：05 坐标 `(x=-1.94, y=-7.56 / 2.44)`，沿 Z 向，Ø3.2（M3）

### 抱箍外壳（06 坐标）

- 外形：`X 0.98~10.98`（厚 10）、`Y -16~36`、`Z 52.63~84.63`
- 小腿槽：`X 0.8~6.1`、`Y -9.8~10.7`、`Z 73.9~84.8`
- SCS225 背面安装面：`X = 10.98`
  - 4 孔 **24.45 × 20.5**：`(Y,Z)=(8.76,58.38)`、`(8.76,78.88)`、
    `(33.21,58.38)`、`(33.21,78.88)`
  - 中心让位：Ø20.4 × 2.6 深（避开 SCS225 后盖 Ø19.2）
- 06 ankle_left 连接：**3× M2.5，R14**
  - `(0.46,54.63)`、`(-13.54,68.63)`、`(14.46,68.63)`
- 05 小腿夹紧：**2× M3**，`(Y,Z)=(±5,76)`
- 脚/脚底让位：背面下边缘切掉，和脚约 0.19 mm、脚底约 0.34 mm 间隙

### C 形连杆（06 坐标）

- 舵盘连接：4× Ø2.8 / R7，基座在 `X≈46.4`，配 SCS225 原装舵盘
- `+Y` 侧长条：`Y 37~42`，避开 SCS225 机体（机体 Y max 35.57）
- 背后横条：`X 0.3~0.9`，`Y 16.5~42`，`Z 62.8~64.5`
- 脚拨片销：`X≈0.6`、`Y=16.5`，M3 螺钉向下；需要 **在脚拨片上钻 Ø3.2 孔**

## 4. FreeCAD 核对

1. 打开 `left_ankle_SCS225_full_check.step`。
2. 量抱箍外壳：**52 × 32 × 10**；小腿槽里能看到切后 05 小腿平板。
3. 量 SCS225 背面 4 孔：**24.45 × 20.5**；确认近排上孔在槽内、没有板（本版只用 3 颗）。
4. 量 3 个 R14 孔到踝轴 `(0.46,68.63)` 的距离都是 **14**。
5. 量 C 连杆基座 4 孔：R7，与 SCS225 舵盘孔同心；连杆长条在机体 `+Y` 外侧。
6. 量间隙：按上表。C 连杆到外壳只有 0.08 mm，打印后建议用砂纸/刀片修一下。
7. 单独打开 `leg_lower_SCS225_cut.step`、`SCS225_ankle_housing.step`、
   `SCS225_ankle_link.step`、`ankle_left_SCS225.step`，运行
   `Part → Check geometry`，都应是单一有效实体。
8. SCS225 的参考 STEP 本身是 8 个重叠实体，FreeCAD 会报 `valid=False`，
   这是参考模型的问题，不影响我们改的零件。

## 5. 打印/装配顺序

1. 打印：
   - `leg_lower_SCS225_cut.step`：先打一条测试腿（切腿不可逆）
   - `SCS225_ankle_housing.step`：6 墙、40% 以上填充
   - `SCS225_ankle_link.step`：5 墙
   - `ankle_left_SCS225.step`：4 墙
2. 外壳背面 3 个 R14 孔装 **M2.5 热熔螺母**；正面 2 个夹紧孔装 **M3 热熔螺母**
   （或在小腿平板上装螺母/热熔螺母）。
3. 把切后 05 小腿平板插进外壳的槽，确认完全到位；用 **2× M3** 从外壳正面
   （舵机那一侧）夹紧小腿。
4. 用 **3× M2.5** 把 06 `ankle_left` 固定到外壳背面（穿过 ankle_left 的 R14 孔）。
5. 把 SCS225 装到外壳正面：
   - **3× M3×8/10**：远排上下 + 近排下
   - 近排上孔不用（槽内无板）
   - SCS225 后盖 Ø19.2 进入外壳中心 Ø20.4 让位
6. 把 C 连杆装到 SCS225 舵盘：
   - **4× M2.5×6**，R7
   - 连杆基座与舵盘之间有约 0.22 mm 间隙，必要时加薄垫片
7. 在脚踝拨片上钻 **Ø3.2** 孔（位置 `X≈0.6, Y=16.5`，从上方钻穿拨片），
   用 **M3×12/16** 从连杆横条向下穿入拨片；先手动确认螺钉长度不顶死。
8. 手动转踝 ±30°，检查：
   - C 连杆不碰 SCS225 机体（0.22 mm）、不碰外壳（0.08 mm）
   - 连杆横条在脚上方（2.35 mm）
   - 脚拨片销不别劲
9. 上电前先不装连杆，确认 SCS225 回中位；再装舵盘、连杆、脚。

## 6. 已知限制

- 05 小腿切端不可逆；先打测试件。
- SCS225 比 HD-1910 大很多，整条腿会变宽；装到整机后要检查左右腿/地面间隙。
- C 连杆是外置大件，外观和惯量都比原设计大；这是为了避开 SCS225 机体的必要代价。
- 近排上背面螺丝省略；如果舵机受力大，建议下一版给小腿开缺口加第 4 孔凸台。
- 脚拨片需要钻孔；如果拨片太薄，可加一个 3D 打印小夹片。
- 这是第一版尺寸/装配验证件，建议先打印外壳 + 连杆 + 测试腿，在桌面上手动
  转踝确认，再上整机。
