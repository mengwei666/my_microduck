# 左踝 SCS225 直接适配（机体在踝内侧 / inboard）

## 0. 这一版做了什么

上一版是把 SCS225 装在一块外置转接板上，舵机整体跑到 `ankle_left` 前面，
输出位置和外形都会外移，所以看起来“突出来”。

这一版改成：

- SCS225 机体放在 `ankle_left` 的 **-X 侧（脚踝内侧）**，和原来的 HD-1910 一样。
- 舵机输出轴仍与踝轴 `(Y,Z)=(0.46,68.63)` 同轴，输出面在 `X=-4.5`，
  和 HD-1910 的安装位置一致，**脚踝输出位置没有外移**。
- 只把 `ankle_left` 内侧和脚后下方做了让位，不改脚踝轴、4 个 R6 舵盘孔、
  脚底和 61700 轴承孔的外形。

## 2. 关键尺寸

- SCS225 机体（按官方图）：**45.23 × 24.73 × 35 mm**
- 输出面：`X=-4.5`（与 HD-1910 相同）
- 舵机姿态：与 HD-1910 一样绕输出轴倾斜 **7°**
- 让位腔（`ankle_left` 内）：
  - 长度方向：`45.25 + 1.2 = 46.45 mm`（上下各约 0.6）
  - 宽度方向：`24.78 + 1.2 = 25.98 mm`（左右各约 0.6）
  - 深度方向：后侧全让开，前侧到 `X=-4.5`，不切舵盘安装面
- `ankle_left`：体积 `6125.5 → 4730.9 mm³`，单一有效实体
- `foot_left`：体积 `12178.1 → 12056.3 mm³`，单一有效实体
- 让位后间隙（按 SCS225/ST3215 参考模型实测）：
  - SCS225 ↔ `ankle_left`：**0.426 mm**（和 HD-1910 的原始间隙相同）
  - SCS225 ↔ 脚：**0.658 mm**
  - SCS225 ↔ 脚底：**1.047 mm**
  - HD-1910 ↔ 改后 `ankle_left`：**0.426 mm**（HD 仍然能装）
- `ankle_left` 的 4 个 R6 舵盘孔、中心孔、脚轴承孔都没有改。

## 3. 必须知道的两个限制

### 3.1 61700 轴承不再使用

原来的 **61700 轴承**在踝轴上、舵机背面（`X≈-36.3~-33.3`）。
SCS225 比 HD-1910 深约 7 mm，机体背面会直接压在这个轴承上
（实测量：SCS225 与轴承重叠 **216.9 mm³**，几乎整个轴承）。

所以这一版：

- 让位时把 `ankle_left` 里 61700 的轴承座一起切掉了；
- 检查装配里**没有放 61700**；
- 踝关节只由 SCS225 输出轴支撑。

如果你一定要保留 61700，舵机就必须整体移到 `ankle_left` **前面**，
也就是上一版的外置抱箍 + C 形连杆方案；那样输出会外移很多，
这就是“突出来”的来源。两者只能选一个。

### 3.2 05 小腿还要改

SCS225 机体背面在 `X=-42.3`，比 HD-1910 的 `-32.5` 深约 9.8 mm，
会进入 05 小腿原来的舵机开口区域。

本包只改了 06 左踝脚，**没有改 05 左小腿**。改 05 时请直接用
`SCS225_fit_reference.step` 做让位/避空；不要再沿用上一版的外置抱箍尺寸，
那一版是按“舵机在踝外侧”做的，和这一版的 inboard 姿态不兼容。

## 4. 在 FreeCAD 里核对

1. 打开 `左踝_SCS225.FCStd`：
   - 量 SCS225 输出轴，应在 `(Y,Z)=(0.46,68.63)`，方向沿 X；
   - 量输出面 `X=-4.5`；
   - 量 SCS225 到 `ankle_left`、脚（如果打开 check 文件）的间隙。
2. 打开 `left_ankle_SCS225_check.step`：
   - 机体到 `ankle_left` 0.426、到脚 0.658、到脚底 1.047；
   - 左右/上下让位间隙约 **0.6 mm**（按 SCS225 官方尺寸 + 0.6 生成）；
   - HD-1910 参考仍在原位置，和改后 `ankle_left` 不干涉；
     **HD 只是对比参考，和 SCS225 会互相重叠，不要同时装。**
3. 单独打开 `ankle_left_SCS225.step`、`foot_left_SCS225.step`，
   运行 `Part → Check geometry`，都应是单一有效实体。
4. SCS225 参考 STEP 本身是 8 个重叠实体，FreeCAD 会报 `valid=False`，
   这是参考模型的问题，不影响尺寸核对。

## 5. 打印/装配建议

1. 打印 `ankle_left_SCS225.step`（4 墙）和 `foot_left_SCS225.step`
   （脚后下方让位很小，打印后用手摸一下有没有毛边）。
2. 本版**不装 61700 轴承**；原来轴承座位置已经被让位腔切掉。
3. SCS225 机体是固定在 05 小腿上的，不是固定在本版 `ankle_left` 上；
   `ankle_left` 仍然通过 4 个 R6 孔和舵盘连接。
   - 装之前先确认你手上的 SCS225 舵盘 4 孔是否也是 R6；如果不是，
     需要加一个舵盘转接片（本包没有做，因为需要按实物舵盘孔距定）。
4. 先把 SCS225 回中位，再装舵盘、`ankle_left`、脚。
5. 手动转踝 ±30°，确认脚、脚底、05 小腿都不碰 SCS225 机体。
6. 上电前先不装脚，确认舵机方向和回中正常。

## 6. 和上一版的关系

- 上一版（`../scs225_left_ankle/`）是“舵机在踝外侧 + 抱箍外壳 + C 连杆”，
  能保留 61700，但输出外移、外形突出。
- 这一版是“舵机在踝内侧 + 切 ankle_left + 切脚”，输出不外移，
  但不再使用 61700，并且 05 小腿必须重做让位。
- 两版不要混用零件。
